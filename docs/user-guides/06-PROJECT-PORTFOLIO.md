# 🏗️ 06: Project Portfolio Management

The Project Portfolio is the organizational hub for all your **Capital Expenditure (CAPEX)** activities.

---

## 🚀 Creating Your First Project

### 1. The Initiation Button
- **Path**: Click **"Project Portfolio"** in the sidebar.
- **Action**: Click the **"+ New Project"** button at the top-right.

### 2. Mandatory Fields
- **Project Name**: Give your project a recognizable title (e.g., *"Lagos Branch Renovation"*).
- **Initial Overall Budget**: The total financial ceiling for this project.
- **Reporting Currency**: Select the primary currency (USD/NGN).

### 3. Advanced Settings (Pro-Tip)
- **Project Type**: Categorize as "Construction", "IT Infrastructure", etc.
- **Timeline**: Set the expected Start and End dates to enable accurate **Time-Variance** tracking.

---

## 📋 Managing the Portfolio

### 🟢 Dashboard View
- **Status Pills**: Every project shows a status chip (e.g., `Active`, `Draft`, `Closed`).
- **Quick Links**: 
  - Click the **Folder Icon** to view project files.
  - Click the **Chart Icon** to go to the project’s specific **Intelligence Dash**.

### 🔍 Project Selection
If you have multiple projects, use the **Search Bar** or **Tenant Switcher** to drill down into a specific business unit's portfolio.

---

## ✅ Best Practices
- **Do Not Reuse Names**: Use unique IDs or year-stamps in names for easier searching.
- **Soft Delete**: If you mistakenly create a project, use the **"Archive"** button. This hides the project from calculation but preserves it for the **Audit Trail**.
