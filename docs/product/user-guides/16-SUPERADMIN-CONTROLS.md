# SuperAdmin Controls

The **SuperAdmin Dashboard** is the platform-level command centre for SentinelFi: management of all tenant organisations, global system health, and billing subscriptions.

---

## Tenant Management

### Global Overview
- **Path**: **SuperAdmin > Dashboard**.
- A high-level view of all active and inactive tenants.

### Managing Organisations
- **Create Tenant** - when a new company joins SentinelFi, the SuperAdmin creates their schema and initial admin account.
- **Deactivate Tenant** - freeze a tenant's data access in cases of missed payments or compliance issues.
- **Scale Tenant** - adjust the maximum number of users or projects allowed for an organisation.

---

## Platform Analytics (Aggregated)

### Global AI Insights
An aggregated view of financial trends across all organisations on the platform, useful for identifying broader market or economic shifts.

### Infrastructure Health
Real-time tracking of Redis cache, AI Agent connectivity, and database load.

---

## Billing and Subscriptions

- **Path**: **SuperAdmin > Billing**.
1. **View Usage** - see how many API calls each tenant has made to the AI engine.
2. **Generate Invoice** - automatically generate platform-level invoices for tenant subscription fees.
3. **Plan Management** - create and modify subscription tiers (e.g., Basic, Premium, Enterprise).

---

## Security and Platform Audits

- **Platform Audit Logs** - track every action taken by admins across the entire ecosystem.
- **Accountability** - this ensures the SuperAdmin is also held accountable by the platform owner.
