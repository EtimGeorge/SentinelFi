# Project Portfolio Management

The Project Portfolio is the organisational hub for all **Capital Expenditure (CAPEX)** activities.

---

## Creating Your First Project

### 1. The Initiation Button
- **Path**: click **Project Portfolio** in the sidebar.
- **Action**: click **+ New Project** at the top-right.

### 2. Mandatory Fields
- **Project Name** - give your project a recognisable title (e.g., `Lagos HQ Renovation - Phase 2`).
- **Initial Overall Budget** - the total financial ceiling (e.g., `2,500,000`).
- **Reporting Currency** - select your primary base (USD or NGN).

### 3. Advanced Settings
- **Project Type** - select from the dropdown (`Infrastructure` for physical builds, `Software` for digital).
- **Timeline** - set Start and End dates (e.g., `2026-04-01` to `2027-03-31`).

---

## Managing the Portfolio

### Dashboard View
- **Status Pills** - every project shows a status chip (`Active`, `Draft`, `Closed`).
- **Quick Links**:
  - Click the **Folder Icon** to view project files.
  - Click the **Chart Icon** to jump to the project's own Intelligence dashboard.

### Project Selection
Use the **Search Bar** or **Tenant Switcher** to drill down into a specific business unit's portfolio when you have multiple projects.

---

## Best Practices
- **Unique Names** - use year-stamps or unique IDs in project names for easier searching.
- **Soft Delete** - if you mistakenly create a project, use the **Archive** button. This hides the project from calculations while preserving it for the Audit Trail.
